# AI 使用记录：Q4 两步含义与路径边界

## 输入

```text
先落地“原地门控补测”，再做“方向探测组滚动决策”  ，这两步分别对应什么（通俗一点）？路径规划有包含在这里吗？
```

## 运行结果

通俗解释了两步的作用与边界：原地门控补测是在一次清除失败后不移动，先判断是否值得原地再测一次；方向探测组滚动决策是在正式清除前，动态比较直接清除与按顺序前往若干安全测点继续定位，并在每次新结果后重新决策、允许提前停止。说明两步均包含各自局部动作的移动距离和下一信号源续程成本，但不包含完整的多信号源全局访问顺序优化；后者仍是独立的路径规划层，应在单源定位与清除策略稳定后再接入。此次仅讨论概念，未修改业务代码或项目状态。
