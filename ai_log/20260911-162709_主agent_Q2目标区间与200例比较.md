# 运行结果

核对 B 题 PDF 后确认原文要求“第二个检测点的候选区域”，并非一维置信区间。分析两个现有目标：离散基线最小化 `T+0.5R_wc`，连续方法最大化有限源边界场景下的鲁棒 FIM/时间。建议 Q2 以有限场景最坏后验包围半径 `R_wc` 为主、动作时间为次级；FIM 只作连续候选生成器，因为 0.5 s/m 不是题目常数，FIM 又只是线性化代理。

新增 `solution/tests/q2/benchmark_200.py`，固定随机种子 20260911 生成 200 个合法配对案例：源和首测点均在半径 1800 m 圆内，距离 100–1000 m，注入误差在 ±1°；已独立检查 200 个真值全部仍在规划器构造的源区域中。16 进程运行耗时约 134.004 s，200 例连续 FIM 均可用。按主指标最坏后验半径，连续 FIM 更优 184/200，即 92%；均值由 119.037 m 降至 109.016 m，中位数由 122.034 m 降至 58.620 m。但另外 16 例平均恶化 609.142 m、最大恶化 636.452 m。按现有工程综合分数 `T+0.5R_wc`，连续 FIM 更优 0/200，平均动作时间多 81.706 s；按 FIM 自身指标则 200/200 更高。

生成逐例结果 `solution/tests/q2/analysis/q2_200_case_comparison.json` 和解释报告 `q2_200_case_comparison.md`，并在 Q2 README 中加入复现命令。建议最终混合裁决在离散点与连续 FIM 点之间按 `(R_wc,T)` 取较优者；本轮只完成分析，没有修改默认选择语义。候选区域建议输出物理保证接收域和近优子水平集 `C_eta={s in F_g: R_wc(s)<=(1+eta)R_wc*}`，用多边形或多多边形描述。未执行 Git，项目状态保持【待验证】。
