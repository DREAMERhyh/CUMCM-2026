# AI 使用记录

本目录收集各 agent 的简要过程记录，最终用于编写支撑材料中的 `AI 工具使用详情.pdf`。规则见根目录 [AGENTS.md](../AGENTS.md)，新记录复制 [TEMPLATE.md](TEMPLATE.md)。本目录不必原样打包提交。

每项任务独立记录，及时更新即可；重点保留“用了什么、为什么用、怎样提示、产生什么、如何修改与核验”，无需存储全部对话。赛前准备与赛中任务在记录中区分，汇总时说明实际使用范围。

## 提交前汇总步骤

1. 收集各 agent 记录，按工具及用途归类，核对工具名称、版本或型号。
2. 汇总具体使用目的和环节、主要提示方式与使用过程，必要时选取典型交互示例。
3. 由队员补齐对 AI 输出的采纳、人工修改和核验情况，明确区分 agent 自检与人工审查。语言润色可按官方规定省略此项详情。
4. 核对日志与最终代码、模型、图表、论文的对应关系；对拟提交的核心建模与分析内容完成必要人工审查与核实。
5. 整理为 PDF，文件名必须是 `AI 工具使用详情.pdf`，放入最终支撑材料；检查文件中不含参赛者、学校及赛区身份信息。

建议 PDF 结构：工具清单、用途与环节、主要提示及过程、采纳与人工修改核验情况、典型交互示例（可选）。不得把未知型号或待核验状态改写成确定事实。

## 论文中的声明

使用 AI 工具时，应在论文参考文献之前设置“AI 工具使用声明”，按实际用途填写：

> 本参赛队在竞赛过程中使用了 AI 工具，主要用于【简要用途，如语言润色、代码调试等】，详细使用情况见支撑材料。

依据：`document/全国大学生数学建模竞赛人工智能工具使用规定 （2026年试行）.pdf` 第 2—4 条，以及同目录论文格式规范中的匿名要求。
