# AI 使用记录

本目录收集各 agent 的任务记录，最终用于编写支撑材料中的 `AI 工具使用详情.pdf`。规则见根目录 [AGENTS.md](../AGENTS.md)，新记录复制 [TEMPLATE.md](TEMPLATE.md)。本目录不必原样打包提交。

每项任务独立记录，只设置“输入”和“运行结果”两个部分。“输入”逐字保存完整的用户提示词或上级 agent 分派内容；“运行结果”简要说明实际输出和检查结果。不要记录系统提示、开发者指令、工具内部参数、思维过程或敏感信息。

## 提交前汇总步骤

1. 收集各 agent 记录，检查每份记录均包含完整输入和对应运行结果。
2. 根据记录整理使用的 AI 工具、具体用途、输入提示词和输出结果。
3. 核对日志与最终代码、模型、图表、论文的对应关系；对拟提交的核心建模与分析内容完成必要人工审查与核实。
4. 整理为 PDF，文件名必须是 `AI 工具使用详情.pdf`，放入最终支撑材料；检查文件中不含参赛者、学校及赛区身份信息。

建议 PDF 结构：工具清单、用途与环节、完整输入、运行结果。汇总内容应与原始日志一致。

## 论文中的声明

使用 AI 工具时，应在论文参考文献之前设置“AI 工具使用声明”，按实际用途填写：

> 本参赛队在竞赛过程中使用了 AI 工具，主要用于【简要用途，如语言润色、代码调试等】，详细使用情况见支撑材料。

依据：`document/全国大学生数学建模竞赛人工智能工具使用规定 （2026年试行）.pdf` 第 2—4 条，以及同目录论文格式规范中的匿名要求。
