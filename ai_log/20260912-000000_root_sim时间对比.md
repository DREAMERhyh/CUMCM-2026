# AI 使用记录：sim 时间对比

## 输入

```text
读取output/sim/中的legacy/和new/，分别计算其中5个jsonl的平均单点虚拟时间消耗、平均真实时间消耗。你也可以自己添加新的计算指标用于比较
```

## 运行结果

读取了 `solution/output/sim/legacy/` 与 `solution/output/sim/new/` 各 5 份 Q3 JSONL。按仓库 `src/sim/cli.py` 的既有定义，将“单点”解释为一个成功清除的信号源：单点虚拟时间为最终累计 `virtual_time_s` 除以成功清除数，单点真实时间为退出记录 `elapsed_real_s` 除以成功清除数。

5 次运行等权平均：legacy 为 466.404083 s/点（虚拟）、9.262557 s/点（真实）；new 为 464.074624 s/点（虚拟）、8.899193 s/点（真实）。新版相对 legacy 分别降低 0.499% 和 3.923%。按全部成功清除点合并加权后：legacy 为 463.964466 s/点、9.403610 s/点；new 为 463.349668 s/点、8.887660 s/点。

补充统计：单次运行单点虚拟时间的样本标准差从 legacy 的 56.902448 s 降至 new 的 24.868457 s；失败清除占全部清除尝试的比例从 23.377% 降至 8.621%；但测量动作数/成功点从 8.8305 增至 10.1321。10 个日志均检查为 HTTP 200、`accepted=true`，累计虚拟时间单调不减。样本仅各 5 次，且每次成功清除数不完全相同，结论应作为描述性比较而非显著性证明。
