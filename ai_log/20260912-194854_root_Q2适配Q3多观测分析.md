# AI 使用记录：Q2适配Q3多观测分析

## 输入

```text
我们./solution/src中的Q2（main分支的），是在已知一点和示向图的情况下选第二个点，但是Q3Q4是在多个选点交汇之后再次选点，Q2的方法是怎么适应Q3的情况的
```

## 运行结果

完成主分支调用链分析。Q3 为每个频道保存全部有效示向观测并在每次新响应后重建多约束交集区域；随后调用 Q2 通用入口 `plan_measurement(track.region, track.observations, ...)` 进行滚动的一步选点。离散集合评分从当前多观测后验出发加入一次假想新观测，因而利用全部历史约束；Q3 还汇总 Q2 顶层、离散、连续多预算、Pareto 和保证域候选，以测量时间加测后清除路线风险重新裁决是否继续测量。确认当前连续 FIM 只显式计算第一次有效示向位置与拟选新位置的两站信息，其他历史观测仅通过当前区域和复评分间接进入；候选生成也仍使用第一次示向角，属于简化边界。Q4 继承多观测区域更新，但通常采用最小包围圆四侧探测，只有该构造不可用时才回退 Q2。此次为只读分析，未修改算法代码、未执行测试。
