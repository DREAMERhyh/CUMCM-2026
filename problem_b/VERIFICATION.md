## 已通过

- Python 标准库 unittest：22 项全部通过。
- 解析几何案例：3×4 矩形直径为 5；等边三角形的直径圆不覆盖全区域；最长顶点对可以是边而非对角线；空集、单点、线段、无界扇区与无界条带的分类。
- 示向规则：四个基本方向、跨 0°、只保留正向扇区、±1° 误差端点、同位置同频道误差固定、重复观测不缩小区域。
- 输入有效性：不满足 `5 < 距离 <= 接收半径` 的手工检测点被拒绝；接收半径边界可接受；同地点冲突误差、重复频道、非有限坐标被拒绝。
- 合成场景：60 个种子，每个场景逐次加入 1—8 个有效观测，共 480 次逐步定位；真值始终包含在交集中，有界区域直径不随新增观测增大。
- 两种生成方式各 20 个种子，每场景 3 个源、12 个检测点；生成可复现，坐标在分布圆内，全部检测点对当前 G1 有效。
- 结构隔离：定位模块仅凭测点和示向度恢复区域；改变绘图范围不改变真实直径；平移场景不改变直径。
- `node --check problem_b/code/visualization/app.js`：JavaScript 语法检查通过。

默认示例：4 个有效观测，6 个定位区域顶点，直径约 36.253324894 m，面积约 687.861791709 m²，真实源位于区域内。以直径端点中点为圆心的直径圆无法覆盖全部顶点，最大超出约 1.193565282 m。
