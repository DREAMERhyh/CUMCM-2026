# B-Q2 验收结果

## 验收范围

本次验收覆盖第二检测点的候选生成、保守物理区域、有限场景最坏半径评分、FIM排序基准、命令行JSON输出和PNG可视化。Q2规划器只接收检测位置、频道和示向度，不接收干扰源真值。

第一观测后的源区域由以下约束构成：±1.005°示向扇区、半径1800米目标域、以第一检测点为圆心的1500米最大接收圆。两个圆域采用外切正多边形，因此近似是保守外包，不会因离散化排除真实源。

## 实际执行

```powershell
python -B -m unittest discover -s code/tests -p 'test_q2.py' -v
```

最终结果：8项测试全部通过，耗时25.295秒。覆盖内容包括：

- 物理区域有界且包含满足误差界的合成真值；
- 相同输入得到确定的相同选点；
- 存在保证接收候选时，返回集合评分最低的保证候选；
- 保证候选为空时安全退化到带无信号分支的候选；
- 非direction输入被拒绝；
- 所有候选分数和时间均为有限合法数值；
- 对所选第二测点构造一组相容观测后，后验区域仍包含真值且不确定半径不增；
- CLI成功输出可解析JSON和非空PNG。

第一次曾使用 `python -B -m unittest code/tests/test_q2.py -v`，因Python标准库模块 `code` 与本项目目录同名而没有加载测试。改用与Q1一致的 `unittest discover` 后正常执行；这不是算法失败。
