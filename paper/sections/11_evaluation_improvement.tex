\section{模型评价与改进}

\subsection{模型的优点}

\begin{enumerate}
  \item \textbf{几何边界明确，关键结论可复核。}
  问题一把示向误差区域表示为凸半平面交，并给出定位区域直径和直径圆覆盖的判据；问题二进一步用外切多边形保守包围源位置区域、用内接多边形构造保证接收域，同时量化多边形近似误差。由此，区域包含关系、定位不确定性和接收保证均有明确的几何含义，表~\ref{tab:q1-validation-short}也表明普通与边界数据的全部检查均通过。

  \item \textbf{四个问题之间形成连续的决策链。}
  模型由问题一的交会定位和最小包围圆出发，在问题二中建立兼顾定位不确定性与行动时间的选点方法，再扩展为问题三的全域扫描、批量定位和开放路径清除，最终在问题四中加入定向可见性、有限状态更新和尾部风险决策。前一问的几何结果被后续问题直接复用，避免了相互独立的局部模型难以组合的问题。

  \item \textbf{理论完成条件与模拟结果相互印证。}
  八点布局和三角网布局分别给出全向源与定向源的发现保证，可靠清除点和有限覆盖队列给出相应的清除条件。表~\ref{tab:q3-log-statistics}和表~\ref{tab:q4-log-statistics}中50次日志的清除比例均为 $100\%$，正式测试又给出了不同干扰源个数下的定位清除时间和程序运行时间，使模型的可执行性具有可量化依据。
\end{enumerate}

\subsection{模型的局限性}

\begin{enumerate}
  \item \textbf{有限离散与替代目标限制了最优性结论。}
  问题二只在有限源位置、误差端点和搜索步长下评价候选点，Fisher 信息也只是定位几何的替代指标。表~\ref{tab:q2-validation-short}显示，连续方案虽在全部场景中减小定位不确定性半径，却只在76个场景中取得更低综合评分。问题四对源位置、接收半径和发射方向的有限状态化同样只能支持当前候选集内的比较，不能代表连续状态空间的全局最优。

  \item \textbf{搜索、定位与路径规划仍采用分阶段优化。}
  问题三先形成清除队列，再对各定位区域中心求开放旅行商顺序，未把当前位置、补充定位过程和清除邻域偏移纳入同一个优化模型；问题四的25点扫描顺序也由最近邻和 $2$-opt 获得。因此，现有方法保证各阶段可执行，并在局部子问题上优化，但不能证明整个任务总时间最短。

  \item \textbf{极端几何和长尾分支的保证具有条件。}
  近共线交会会触发微小浮点容差，表~\ref{tab:q1-validation-short}中仍有3项退化检查失败。问题三在定位半径超过 $80\ \mathrm m$ 时会截断保底清除点队列，问题四也用有限探测组和有限状态近似处理复杂无信号分支。因而，当前完成性结论应限定在几何近似、保底清除点上限和模拟器测试覆盖的条件内。
\end{enumerate}

\subsection{模型的改进方向}

\begin{enumerate}
  \item \textbf{采用自适应几何精度。}
  可根据交会边界的夹角和当前定位区域尺度动态增加圆形外包边数，并在近共线交点处使用稳健几何判定或更高精度运算。这样既能保留普通场景的计算效率，又能减少退化场景中的容差触发和不必要的区域膨胀。

  \item \textbf{直接围绕最终评价指标优化选点。}
  问题二可在区域边界高敏感位置自适应增加源场景，并以最坏定位不确定性半径和行动时间直接进行多目标搜索，减少 Fisher 替代目标与最终综合评分之间的偏差。问题四可依据实际检测结果动态调整有限状态的采样密度和权重，使计算资源集中到仍难区分的发射方向与源位置。

  \item \textbf{将定位、清除与路线进行滚动联合规划。}
  可把机器狗当前位置、下一次检测的区域收缩、清除邻域和后续源访问顺序纳入统一的有限时域模型，每获得一次真实响应便重新规划。对于定位半径较大的频道，则按未覆盖区域自适应生成清除点，而不是固定截断保底清除点序列，从而在保持保底能力的同时减少冗余移动。
\end{enumerate}

\subsection{适用范围与推广}

本文模型适用于目标区域有界、方向观测误差有界、移动与检测耗时可量化，并能在每次行动后获得反馈的移动式搜索定位任务。若用于其他传感器或作业平台，只需重新定义可见性条件、测量误差区域、作用距离和行动时间，即可沿用“保守可行域更新---保证接收选点---滚动反馈决策---路径清除”的总体框架；但在新的噪声分布、遮挡条件或动态目标环境下，仍需重新验证覆盖条件和参数设置。
