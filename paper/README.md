# 2026 全国大学生数学建模竞赛论文模板

本目录由下载的 CUMCMThesis 模板整理而成，只保留正式参赛论文需要的文件和空目录。主文件为 `paper.tex`，请使用 XeLaTeX 编译：

在 Windows 宿主机上，可直接用 TeXstudio 打开 `paper.tex`，将默认编译器设为 XeLaTeX；也可以在该目录打开 PowerShell 或命令提示符运行：

```bash
xelatex paper.tex
xelatex paper.tex
```

也可以使用：

```bash
latexmk -xelatex paper.tex
```

## 文件说明

- `paper.tex`：电子版论文主文件；默认不生成承诺书和编号专用页。
- `cumcmthesis.cls`：原模板文档类，版本 2.9（2026-08-26）。
- `cumcm2026.sty`：论文常用排版设置及 2026 年 AI 工具使用声明命令。
- `figures/`：论文图片；建议使用含义明确的英文文件名。
- `code/`：完整、可运行的源程序副本；支撑材料中也应包含相同源文件。
- `code/q2_region_figures.py`：复用现有 Q1/Q2 几何函数生成问题二的源位置外近似图、接收域关系图和有限源位置场景抽样图，同时检查高密度 $K_1$ 边界点均位于 $\widehat K_1$ 内。

## 论文建模写作规范

1. 写作前先阅读题目、现有代码、测试和分题文档，确认论文算法与实际实现一致。先完成问题分析，再说明建模与证明思路；经队员确认后撰写完整模型。发现模型边界或题意疑点时，先讨论清楚再修改正文。
2. 问题分析保持简洁。题目已经给出的方法和条件直接引用，不重复长篇推导。主要说明本问需要解决的数学对象、关键结论及各步骤之间的关系。
3. 模型假设只保留为构造数学模型而由本文引入的假设或近似，不重复罗列题目已经明确给出的背景假设、条件或设定。推导中需要使用题设条件时，应将其表述为题目已知条件，而不是本文的模型假设。本文引入的假设可分为“四问通用假设”和“分题假设”：共同采用的建模假设统一放在通用假设中，仅服务于某一问的假设放入对应分题；重要近似需说明依据和适用范围。
4. 模型使用数学语言描述，不按程序结构编写。优先从集合、几何、优化目标和约束关系建立模型；算法步骤应与代码一致，但正文重点放在数学原理、正确性和复杂度，不展开代码实现细节。
5. 所有模型符号应先在符号说明中定义，并给出准确单位。几何点需要参与距离和向量运算时，应明确写成位置坐标，例如 $S_i=(x_i,y_i)\in\mathbb R^2$，坐标单位为 $\mathrm m$。同一符号不得在几何点、坐标、集合等不同含义之间混用。
6. 关键数学结论使用“命题—证明”的形式。命题名称加粗、命题内容使用楷体，证明结尾添加 $\square$。本文核心结论应给出完整证明；成熟定理和经典算法优先引用权威文献，避免重复证明。
7. 引用定理时，正文不能只写“采用文献中的方法”，而应说明文献证明或给出了什么定理、该定理成立所需的条件、本文模型为何满足这些条件，以及该定理具体用于哪一个求解步骤。文内引用和参考文献条目必须同时存在，并优先采用原始论文、正式出版物或作者提供的资料。
8. 插图采用简洁、抽象的数学几何风格，只保留证明所需元素。图形可以不按比例，但几何关系必须正确；使用颜色、线型和标注区分不同区域，并检查曲线、填充、顶点和文字的图层顺序。可重复生成的图片应保留绘图脚本。
9. 完成修改后检查符号、公式编号、标签、交叉引用、文献引用、图片文件和 LaTeX 环境是否匹配。Linux 环境只进行静态检查和图片检查；最终使用 Windows XeLaTeX 重复编译并人工检查字体、分页、图注和交叉引用。
10. AI 参与的内容按 `ai_log/` 规则记录完整输入和运行结果。核心建模、证明、引用和最终表述由参赛队逐项复核。

## 提交前检查

1. 电子版第一页是摘要专用页，页码从 1 开始，且没有承诺书、编号专用页或目录。
2. 标题、摘要和关键词合计不超过一页；正文不超过 30 页，附录页数不限。
3. A4 页面四边页边距均不少于 2.5 cm；页码位于页脚中部。
4. 摘要、正文、附录、PDF 元数据和支撑材料中均无参赛者、学校、赛区等身份信息。
5. 所有公开资料均在正文引用处标注，并在参考文献中列出。
6. “AI 工具使用声明”位于参考文献之前，文字与实际使用情况及 `AI 工具使用详情.pdf` 一致。
7. 附录列出全部支撑材料文件和完整可运行代码；没有程序或支撑材料时，使用官方规定的明确表述。
8. 纸质版需另行在论文前加入官方承诺书和编号专用页；电子版及支撑材料不得包含这两页。
9. 最终电子版应为单个 PDF 或 Word 文件，内容与纸质版正文及附录一致，文件不超过 20 MB，且不要压缩论文文件。

所有“待填写”文本、示例公式、示例表格和提示语都应在提交前替换或删除。核心建模与分析内容须由参赛队逐项审查和核实。
