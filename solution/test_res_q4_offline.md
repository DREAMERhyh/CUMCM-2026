# 历史记录：B-Q4 Offline 验收结果

> 本文件仅保留重构前的离线原型测试记录，不代表人工或官方模拟器验收。

## 验收范围

当前未接入官方模拟器。本文件只验收定向源的121点全局覆盖、四方向局部复核证书、Q3共享状态机上的定向策略，以及有限清除保底。

## 实际执行

```powershell
python -B -m unittest discover -s code/tests -p 'test_q4_offline.py' -v
```

结果：4项测试全部通过。

- 固定种子抽取3000组目标圆内位置和发射方向，121点网格中每组至少存在一个处于发射正面且距离不超过1000米的检测点；严格保证仍来自几何证明。
- 四方向复核函数在满足 `rho/sqrt(2)>r` 且 `rho+r<=1000` 时返回四点，在不满足证书时拒绝生成。
- 对72个方向检查局部四点中至少一个可见。
- 一个固定背向原点的定向源在4000动作上限内被离线策略发现并清除，其余19频道在完整121点扫描后获得无源证书。

另以默认两次改进测量配置运行固定场景，2480个动作后正常退出并清除频道7。

## 离线演示

```powershell
python code/q4/cli.py --output output/q4_offline/demo.json
```

固定演示执行2478个动作，清除频道7，离线虚拟时间约28167.814秒。较大动作数正说明121点方案只是可证明的保底，不是已验证的高效正式策略。
