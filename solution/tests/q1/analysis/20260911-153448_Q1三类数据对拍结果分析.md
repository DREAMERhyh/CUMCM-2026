## 2. 状态分布的解释

- **random 的 4 个 unbounded**：`gen_data.py` 的 `DETECTOR_COUNTS=(1,2,3,4,6,10)` 中，24 个用例有 4 个只含 1 个检测点。单条示向线 ±1° 切出无限长楔形，区域无界、直径为 `null` 是数学上的正确结论（对应 `test_unit.py` 的 `test_unbounded_region_never_uses_viewport_diameter`）。
- **adversarial 的 6 个 unbounded**：6 个用例只有 2~3 个近共线检测点，楔形交不出封闭区域，同样正确。
- **boundary 全部 bounded**：源点贴近 1800 m 分布域边缘、误差恰好取 ±1.0°（踩在误差边界上），630 项检查全过，说明误差边界数值处理稳定。

## 3. 3 项失败的定位

全部失败落在 `_check_contraction`（`test_duipai.py:121-132`）的同一断言：**有界区域直径应随观测逐次增加而单调收缩**（观测增加 ⇒ 半平面增加 ⇒ 区域只会缩小 ⇒ 直径不允许变大）。

失败明细（注意：文件名 1 起始而 `case_id` 0 起始，日志中的 `adversarial_42_0011` 对应 `case_0012.json`）：

| 用例 | 文件 | 直径序列（m） |
|---|---|---|
| adversarial_42_0011 | case_0012.json | None → 941.0 → 861.35 → **6.136e-05 → 6.654e-05**（n=4→5 变大） |
| adversarial_42_0015 | case_0016.json | None → None → None → 2.383e-05 → 2.383e-05 → **2.761e-05**（n=5→6 变大） |
| adversarial_42_0023 | case_0024.json | None → 953.0 → 873.33 → **6.471e-05 → 7.274e-05**（n=4→5 变大） |

## 4. 根因分析（50 位精度十进制重算验证）

**这不是收缩逻辑错误，而是退化构型下的浮点噪声。** 验证链条：

1. **数据踩在最极端组合上**：adversarial 模式（`gen_data.py:50-58`）生成近共线检测点（6 点横排 450 m、纵向抖动 0.2 m），且误差循环取 (-1, 0, 1) 恰好 ±1.0°。以 case_0012 为例，真值源 (111, 39)，所有 wedge 边界线几乎全部穿过真值源，精确数学上区域退化为一个点。
2. **精确区域实际为空**：用 50 位 `decimal.Decimal` 重放 n=4 的 8 条半平面，所有成对交点的最小约束违约量为 **7.4e-09 m > 0**，即双精度 `sin/cos` 舍入后真值点落在全部约束之外约 7 纳米，精确意义区域为空集。
3. **容差把空区域"救活"**：求解器容差 `TOL = 1e-7`（`geometry.py:11`，`contains` 于 `geometry.py:26-27`）判定这些近可行点可行，区域被恢复成一根**针状细条**：长约 6e-5 m（0.07 mm）、宽约 1e-8 m。
4. **顶点恢复由噪声主导**：`intersect_halfplanes`（`geometry.py:171-180`）在近共点直线的两两求交中，交角 1e-4~1e-8 弧度量级，哪些交点通过容差检验取决于浮点噪声。第 5 条观测加入后，针尖顶点从 111.0000170 挪到 111.0000222（挪动 5.2e-6 m），直径随之"增大"。

## 5. 结论与建议

**物理结论仍然正确**：全部顶点距真值源不足 0.07 mm，为分布域尺度（3600 m）的一亿分之一量级；直径增量 5e-6 m 同样在容差语义之内。该失败正是 `src/q1/README.md`「测试与局限」一节预告的"近平行边界可能放大数值误差"的实证，也是 adversarial 套件的设计目的所在。

按 `verify_manual.md` 约定，失败应记录进 `test_res.md`、Q1 状态保持【待验证】，处理方式由队员决定。可选方向：

1. **接受为已知局限**：在 `test_res.md` 记录，adversarial 退化用例豁免单调性检查；
2. **给检查加物理下限**：直径小于某阈值（如 1e-3 m）时跳过单调性断言——0.07 mm 的区域在题目尺度上等价于"已定位源"；
3. **加固求解器**：顶点恢复时对近共点边界线做容差松弛或高精度算术。
