# Q2 两种选点方案的 200 例配对比较

当前状态：【待验证】。本报告是合成数据上的程序比较，不是官方模拟器结果，也不构成连续全局最优证明。

## 1. 统一评价目标

题目 Q2 要求“获得较好的定位效果”。因此本报告把有限场景下第二次测量后的最坏最小包围圆半径作为主指标：

\[
R_{\rm wc}(s)=\max_{g,e} r_*\bigl(P_1\cap W(s,\theta(g,s)+e)\bigr),
\]

其中 \(g\) 遍历当前源区域的代表场景，\(e\in\{-1.005^\circ,0,1.005^\circ\}\)，\(r_*\) 是后验区域最小包围圆半径。该指标越小，最坏情况下剩余定位区域越小。动作时间作为次级指标；现有工程综合分数

\[
J(s)=T(s)+0.5R_{\rm wc}(s)
\]

也一并报告，但其中 0.5 s/m 是工程权重，不是题目给定常数。

## 2. 数据生成与复现

- 随机种子：`20260911`。
- 共 200 例；源和首测点均在半径 1800 m 的目标圆内。
- 源到首测点距离为 100–1000 m，保证首测可收到信号。
- 注入示向误差位于 ±1°；规划器只接收首测点、频道和带误差示向度，不读取合成真值。
- 两种方案在同一输入上配对运行；选点参数使用 `Q2Config` 默认值，仅关闭与选点无关的近优域绘图采样以缩短批量试验时间。

复现命令：

```powershell
python -B tests/q2/benchmark_200.py --count 200 --seed 20260911 --workers 16
```

逐例输入与输出保存在 `q2_200_case_comparison.json`。

## 3. 比较结果

| 指标 | 离散基线 | 连续 FIM | 连续 FIM 更优 |
|---|---:|---:|---:|
| 最坏后验半径均值 | 119.037 m | 70.082 m | 200/200 = **100%** |
| 最坏后验半径中位数 | 122.034 m | 75.050 m | 同上 |
| 综合分数均值 | 169.573 s | 174.802 s | 76/200 = **38%** |
| 综合分数中位数 | 201.759 s | 199.701 s | 同上 |
| 鲁棒 FIM 指标 | - | - | 200/200 更高 |

连续 FIM 点的动作时间平均比基线多 29.706 s，符合“执行点最多比基线多 30 s”的配置。它在全部 200 例中缩小主指标，平均减少 48.955 m；但工程折中分数只在 38% 的案例更低，说明 `R` 与 `T` 必须分别报告。

相较旧的无动作时间约束 FIM，本版先在 15/30/60 s 三档额外虚拟时间预算下搜索，再把所有候选送回有界误差集合评分器。这样既避免了远距离高 FIM 点导致的 80 s 级额外移动，也防止仅凭线性化 FIM 指标直接裁决。

## 4. 建议决策规则

对 Q2，以最坏后验半径为主目标、动作时间为次级目标；连续 FIM 只负责产生一个高信息候选。最终在“离散基线点”和“连续 FIM 点”之间重新计算同一集合指标并取较小者：

\[
s^*=\arg\min_{s\in\{s_{\rm discrete},s_{\rm FIM}\}}
\bigl(R_{\rm wc}(s),T(s)\bigr).
\]

在本批 200 例中，该混合裁决选择连续点 200 次；按当前有限场景主指标，它不会比离散基线更差。这个 **100%** 是固定数据集与有限场景评分器上的实验比例，不是连续全局最优概率，也不能解释为总任务一定更快。若 Q3/Q4 更看重总耗时，应从输出的 `pareto_front` 中进一步按剩余时间选点，而不是只看 FIM 数值。

## 5. “候选区域”而不是单点

题面原文要求的是第二检测点的“候选区域”。可分两层描述：

1. 物理可行区域：保证接收域
   \(\mathcal F_g=\bigcap_{q\in P_1}B(q,1000)\)，以及可能接收域
   \(\mathcal F_p=P_1\oplus B(0,1500)\)。当前程序已输出这两个二维多边形近似。
2. 定位效果较好的选取区域：在保证接收域内定义近优子水平集
   \[
   \mathcal C_\eta=\{s\in\mathcal F_g:
   R_{\rm wc}(s)\le(1+\eta)R_{\rm wc}^*\}.
   \]
   程序同时给出 \(\eta=5\%\) 和 \(10\%\) 的局部采样近似，并附加
   \(T(s)\le T(s^*)+10\,\mathrm{s}\) 条件。

`s*` 是从候选区域中选出的推荐代表点，不应拿一个 x 区间和一个 y 区间代替该区域，因为近优集合可能倾斜、弯曲甚至不连通。程序输出多边形、面积和以首测示向为纵轴/左法向为横轴的局部坐标范围。当前多边形只是达标采样点的凸包；仅采样点经过评分验证，凸包内部不构成连续证书，论文中必须写“5%/10% 近优域近似”。

本次 200 例并行运行墙钟时间为 122.015 s（16 进程）。单个固定演示在当前机器上的粗测为：仅离散基线 3.741 s，FIM 且不生成近优域 4.115 s，默认在线近优域 6.919 s，离线较密近优域 17.227 s。机器负载会影响这些真实时间，题目的机器狗虚拟时间不受这些数字影响。
