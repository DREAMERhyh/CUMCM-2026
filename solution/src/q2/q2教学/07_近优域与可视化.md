# Q2 零基础教学（07）：近优域与可视化

前面得到的"最终推荐点"是单点。可题面要的其实是**候选区域**——"在这一片里选，
效果都差不多好"。这一篇讲程序怎么把它画出来（5%/10% 近优域），以及那张三联图怎么读。
对应代码 `q2/near_optimal.py` 和 `q2/plot.py`。

---

## 1. 题面要"候选区域"，我们已给了哪两层？

`API.md` 把它分两层回答：

**第①层——物理可行区域**（几何上不允许越界的地盘）：
- **保证接收域** F_g = ∩_{q∈P₁} B(q, 1000)：放在这**必然**收到信号（第 03 篇）；
- **可能接收域** F_p = P₁⊕B(0,1500)：放在这**可能**收到。

**第②层——定位效果好的选取区域**：在保证域内，进一步只挑"效果接近最好"的：
- 定义一个相对容差 η（比如 5%、10%）：
  ```
  C_η = { s ∈ F_g : R_wc(s) ≤ (1+η) · R_wc(s*) }
  ```
  其中 R_wc(s*) 是推荐点 s* 的最坏半径。意思是"最坏半径不超过最好的 1.05 倍/1.10 倍"的区域。

近优域回答第②层，并额外加了时间限制 `T(s) ≤ T(s*) + 10s`（未完，见下文）。

---

## 2. 近优域具体怎么做（采样 → 筛 → 凸包）

`q2/near_optimal.py`。由于无法对连续区域逐点验证 R_wc，它退而求其次：**采样**。

**第一步：在推荐点附近撒局部点** `local_sample_points`（`near_optimal.py:19-39`）：

| 模式 | 半径集合 | 方向数 | 什么时候用 |
|---|---|---|---|
| `online` | (20, 40) m | 8 | 现场计算快（默认） |
| `offline` | (10,20,40,60,80) m | 16 | 论文精细图，慢 |
| `off` | 只有中心 | 0 | 不做近优域 |

- 以 `center`（每个分支自己的推荐点）为心，画若干半径环 + 均匀方向，得到采样点；
- 每个采样点用 `project_to_polygon` 投影回保证接收域；
- 按 `round(点,8)` 去重。

**第二步：逐个验证并筛选** `build_near_optimal_regions`（`near_optimal.py:61-120`）：

对每个容差 η ∈ {5%, 10%}：
```
radius_limit = R_wc(reference) · (1+η)
time_limit   = T(reference) + time_slack_s   # 默认 +10s
qualified = 采样点中满足 R_wc ≤ radius_limit 且 T ≤ time_limit 的全部
```

**第三步：凸包绘图**：
- 取 `qualified` 各点的凸包 `hull(...)`，作为该近优域的多边形；
- 输出 `5pct`、`10pct` 两级（10% 一定 ⊇ 5%，因为容差更宽）。

## 3. 极其重要的免责声明：这只是"绘图近似"

README/API/分析报告三处都反复强调，文档里写清楚：

> 近优域多边形只**逐点验证了采样点**满足阈值；**凸包内部**以及采样点之间
> 没有逐点验证，因此不是连续置信区域，也不是严格子水平集证书（certificate）。

代码里 `approximation.kind = "convex_hull_of_verified_local_samples"`、
`continuous_certificate = False`，并带一句 `warning`。

**论文写作红线**：只能写"5%/10% 近优域近似"，**绝不能说"置信区间"**或真正意义的子水平集。
这既是工程诚实，也避免审稿人挑刺。

## 4. 可视化：那张三联图怎么读

`q2/plot.py:plot_plan` 画一张大图，分三栏。默认 `python src/q2/cli.py --demo --output out.png`。

**左栏：地图总览**
- 淡蓝多边形：第一观测后的**源位置域 P₁**；
- 橙、绿多边形：可能接收域（外近似）与保证接收域（内近似）；
- 彩色散点：46 个离散候选（颜色=综合分数，viridis_r，越偏紫分越高）；
- 红星：离散基线选中点；蓝菱形：连续 FIM 结果；黑色空心圆：**最终推荐点**；
- 红色实/虚线：基线 5%/10% 近优域；蓝色实/虚线：FIM 的 5%/10% 近优域；
- 右下两个小窗：基线与 FIM 近优域的局�部放大图。

**中栏：时间—定位效果 Pareto 折线**
- 横轴虚拟动作时间 T/s，纵轴最坏后验半径 R_wc/m，**越靠左下越好**；
- 灰点连成 Pareto 折线，标着每个点的工程分数 J；
- 红星=离散，蓝菱=FIM。一看就知道"多花几秒换多少精度"。

**右栏：前 15 个离散候选的不确定性横向条形图**
- 横轴是每个候选的 R_wc；绿=保证接收，黄=非保证。一眼看出哪些点"最后嫌疑范围小"。

## 5. 命令行怎么用不同档位

```powershell
python src/q2/cli.py --demo --no-show --region-mode online --output out.png --result-json out.json
python src/q2/cli.py --demo --no-show --region-mode offline --output out2.png   # 更密、更慢
python src/q2/cli.py --demo --no-show --region-mode off --output out3.png       # 只比选点，快
```

- `own-line`：现场（默认，CPU 上限 5s）；`offline`：论文图（上限放宽到 25s）；
`off`：不改推荐点，只是不算近优域。
- **无论哪种档位，近优域只是一层可视化，不改变最终推荐点**。

demo 实际：近优域为 `disabled`（我跑用 `--region-mode off`），`planning_cpu_wall_time_s≈8.2 s`。
