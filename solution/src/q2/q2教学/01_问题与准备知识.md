## 1. Q2 到底要我们干什么？

想象你在一座圆形赛场里找一台隐形的干扰源机器。赛场半径 1800 m（约 3.6 km 直径）。

你控制的机器狗先在 **S₁ 点**停下，用天线一测：收到了某频道信号，还测出一个"示向角"，
也就是干扰源大概在哪个方向。但有两个麻烦：

1. **只知道方向，不知道距离**——干扰源可能近在几米，也可能远在几百米外。
2. **方向有误差**——测出的示向角可能偏 ±1°。

换句话说，第一次测量之后，你只知道干扰源**藏在某一整片区域里**，不确定具体在哪。

现在题目 Q2 问你：

> 机器的当前位置是 S₁（你已经在 S₁ 了）。要决定**把机器开到哪个第二位置 S₂**，
> 再做一次测量，让"两次测量的结果一交会"，干扰源被定位得尽可能准。
> 同时：别让我跑太远、别让我白跑（要能收到信号），并给出 S₂ 的**候选区域**。

用捉迷藏比喻：你在 A 点听到小熊从某个方向发出声音，但不知道它躲在哪。
现在要挑一个 B 点再听一次——B 点选在哪，两次声音交汇起来，才能最快确定小熊的树洞？

这就是 Q2。代码把它拆成了"两部分答案"：

- **选一个推荐点 S₂***：供后续 Q3/Q4 真正去跑的位置；
- **给一片候选区域**：不只是单点，而是"在这一片里选，效果都差不多好"的范围。

## 2. 预备知识（0）：坐标系与坐标

整套代码的世界里，地面是一个平面。用 **x 向东、y 向北** 的直角坐标系。

- 一个点写成 `(x, y)`，单位是**米**。
- 首测点 S₁ = `(-600, -300)`，就是"在原点往西 600 m、往南 300 m"。

| 概念 | 含义 | 例子 |
|---|---|---|
| 点 (x, y) | 平面上的一个位置 | S₁ = (-600, -300) |
| 两点距离 | 欧氏距离，勾股定理 | 从 (0,0) 到 (3,4) 是 √(3²+4²)=5 m |

代码里距离都用 `math.dist(a, b)` 算，就是勾股定理。坏了就用这个：
`dist((x1,y1),(x2,y2)) = sqrt((x2-x1)² + (y2-y1)²)`。

## 3. 预备知识（1）：方位角（示向度）

**方位角**是"从正东方向起、逆时针转多少度才能对准目标"。

- 正东 = 0°；正北 = 90°；正西 = 180°；正南 = 270°。
- 代码里叫 `bearing_deg`，范围是 **0 ≤ θ < 360**，单位**度**（不是弧度）。

从点 S 到点 G 的真方位角，数学上是：

```python
true_bearing = degrees( atan2(Gy - Sy, Gx - Sx) )  % 360
```

`atan2` 是"能分辨象限的反正切"——它同时看横纵差，得到 [−180, 180] 的角度，
再 `% 360` 把它转到 [0, 360) 方便比较。

> 直观：干扰源在 S₁ 的**东北方向**，示向角大概在 0°~90° 之间；
> 在西南方向，大概在 180°~270° 之间。

**误差**：测量到的示向 θ_meas，干扰源真方向 θ_true 满足 `|θ_meas − θ_true| ≤ 1°`。
所以"方向未知"其实是一整块**扇区**：真方向可能落在 `θ_meas ± 1°` 之间任意处。

## 4. 预备知识（2）：半平面与半平面交集

一条直线把平面切成两半，其中一边组成的区域叫**半平面**。

代码里每条"约束"都写成一个半平面：

```python
(a, b, c)  表示   a·x + b·y ≤ c
```

例如 `(1, 0, 400)` 就是 `1·x + 0·y ≤ 400`，即 **x ≤ 400**——点 (300, anything) 都在里面。

**半平面交集**：把很多个半平面"叠"在一起，同时满足所有条件的点构成的区域，
通常就是一个**凸多边形**。这正是 Q1 里处理过的核心问题。

```
两个半平面：x ≤ 400  和  x ≥ -100
交集：-100 ≤ x ≤ 400，这是一条垂直的条带           （无界）
再加：y ≤ 300  和  y ≥ -200 ⇒ 变成一个矩形          （有界）
```

代码在 `q1/geometry.py` 的 `intersect_halfplanes` 里做这件事：
输入一堆 `(a,b,c)`，输出「空 / 无界 / 有界+凸多边形顶点」。后面全篇都会用到它。

## 5. 预备知识（3）：凸包

给一堆点，**凸包**是"用一根橡皮筋把它们全部圈住"后形成的最小凸多边形。

- 橡皮筋绷在点堆最外面的凸角上，里面的点都不在顶点里。
- 代码在 `q1/geometry.py` 的 `hull(points)` 里用"单调链"实现。

例子：10 个点里可能只有 5 个在凸包顶点上，橡皮筋就是那 5 个围成的五边形。

**为什么用凸包**：凸多边形比杂乱点集好处理（顶点顺序确定、可判断点在不在内、
面积好算）。后面"保证接收域""近优域"都需要它来把一片采样点整理成干净的多边形。

---

## 6. 预备知识（4）：最小包围圆

**最小包围圆（Minimum Enclosing Circle, MEC）**：能包住某一堆点（或一个多边形）
的**半径最小**的圆。

- 它由 1、2 或 3 个边界点"撑住"（数学上的支撑定理）。
- 代码在 `q1/geometry.py` 的 `minimum_enclosing_circle` 里做法是**枚举所有 1/2/3 点组合**、
  逐个检查是否罩住全部点、取半径最小的——O(n⁴)，对本题顶点数量（几十个）完全够用，且可审计。

**为什么用它**：我们用"MEC 半径"来衡量"定位有多准"。测完一个区域后，
用一个圆就能罩住所有可能源位置，**这个半径越小，说明定位越准**。这个量全篇反复用于打分。

## 7. 预备知识（5）我们还没讲的一个词：FIM

FIM 是"Fisher Information Matrix（费雪信息矩阵）"的缩写，第 05 篇会专门讲公式和直觉。
现在只需先记住一句话：

> FIM 用一个数衡量"这一组观测能挖出多少关于目标位置的信息"。
> 对"两次测方向角"来说，信息大致取决于两个测点看同一个源时**夹角夹得好不好**
> （越接近 90° 越好）和**离源近不近**（越近视角变化越大）。越大越好。
