# Q2 零基础教学（02）：源区域 P₁ 是怎么来的

上一篇备好了 6 个工具。这一篇用它们把"第一次测量后，干扰源可能藏在哪"的
那片区域 **P₁** 完整造出来。全部对应代码 `common/domain.py`。

先记住提交的行事章程：**这片区域要"保守"**——宁可大一点，绝不能把真源漏掉。

---

## 1. 三个条件叠加出 P₁

第一次测量后，真源位置 G 一定同时满足下面三条，缺一不可：

**条件 A：在赛场目标圆内**（赛场就 1800 m 半径，干扰源总不至于跑出场）

```
G 在 B(0, 1800)   —— 圆心原点、半径 1800 的圆盘
```

**条件 B：S₁ 能收到它的信号**（能收到 = 距离不超过它的最大有效接收半径 1500 m）

```
G 在 B(S₁, 1500)  —— 圆心 S₁、半径 1500 的圆盘
```

**条件 C：方向落在示向度 ±1° 的扇区内**

```
G 在 W(S₁, θ_meas ± 1°)  —— 以 S₁ 为顶点的"方向楔形"
```

三者的交集就是：

```
P₁ = B(0,1800) ∩ B(S₁,1500) ∩ W(S₁, θ_meas ± 1°)
```

**一句话**：真源一定在 P₁ 里；反过来说 P₁ 里的每个点都说不好是不是真源。
这就是"嫌疑范围"。

### 我们的 demo 数字（S₁=(-600,-300)，示向度 35.89°）

本机实际运行：P₁ 是**有界三角形**，三个顶点约是
`(-600, -300)`、`(634.9, 561.0)`、`(608.3, 607.1)`，面积 **39890.5 m² ≈ 0.04 km²**。

- 为什么是三角形？因为"方向楔形"（条件 C）这一下就把大片区域砍掉了，
  只留下一块接近三角的形状。
- P₁ 的**最小包围圆**：中心约 `(4.2, 153.5)`、半径 **755.5 m**。
  这个"罩住整个嫌疑区的圆半径"叫 `current_radius`，后面评价"不测会不会更差"时反复用到。

## 2. 关键问题：圆怎么交给"半平面求交"？

半平面是"直线一边的区域"，可圆不是直线。怎么让求交器理解"圆盘"？
**做法：用正多边形近似圆。**

代码里有两个方向，含义完全不同，务必分清：

| 类型 | 多边形 ⊂ 圆 还是 ⊃ 圆 | 保守方向 | 代码 |
|---|---|---|---|
| **外切多边形** | 多边形**包住**圆（⊃） | 往"会多包含"方向偏，不漏源 | `common/domain.py:circle_outer_planes` |
| **内接多边形** | 多边形**在圆里**（⊂） | 往"更严格"方向偏，保证达标 | `q2/candidates.py:_inner_circle_*` |

对 P₁ 来说，圆盘 B(0,1800) 和 B(S₁,1500) 都可能包含真源，所以**必须用外切多边形**，
确保"多边形 ⊇ 真圆 ⊇ 真源"，一个真源都不漏。

## 3. 粗外切与局部圆弧细化怎么做（代码）

`common/domain.py:circle_outer_planes(center, radius, sides)`：

```python
def circle_outer_planes(center, radius, sides=32):
    cx, cy = center
    planes = []
    for k in range(sides):
        angle = 2*math.pi*k/sides                # 均匀取 sides 个方向
        nx, ny = cos(angle), sin(angle)          # 法向量（指向圆外）
        planes.append((nx, ny, radius + nx*cx + ny*cy))
    return planes
```

- 每个方向 `angle` 对应一条**圆的切线**：`n·(x − center) ≤ radius`。
  `sides` 条切线先围成一个完整保留的粗外切正多边形。
- 程序随后解析求可行的线—圆和圆—圆交点，在实际参与边界的圆弧端点补切线；若输出顶点相对真实圆盘的径向超差仍过大，再沿该顶点方向迭代补切线。
- P₁ 默认从 `circle_sides=24` 起步，停止目标等于整圆 48 边外切的理论径向误差；它只细化有效局部圆弧，不等于把所有圆直接改成 48 边形。

> 直观图：把一枚硬币放在 24 条切线中间，切线围出的就是一个贴着币边的 24 边形，
> 它完全罩住硬币。

**为什么"外切"= 保守不漏源**：真源必然在真圆内 ⊂ 外切多边形内，所以加入这条约束后，
多边形内的候选仍包含真源。数学上这是"对真区域的外近似/保守近似"。

## 4. 方向楔形怎么转成半平面（用 Q1）

方向楔形"以 S₁ 为顶点、朝向 θ、张开 ±1°"，是一条窄缝。Q1 已经写过函数：
`q1/geometry.py:bearing_planes(position, bearing_deg, error_deg)`，
返回**两条归一化半平面**，把楔形表示成"这两条边各自一边"的交集。

对应代码在 `common/domain.py:build_region_from_observations` 里：先组装粗外切圆和平面约束。默认 `q2_version="new"` 再交给自适应圆弧求交器；`legacy` 则直接对固定外切半平面求交，便于和旧版同条件比较。

```python
base_planes = circle_outer_planes((0,0), arena_radius, circle_sides) # 条件A粗外包
for obs in observations (result == "direction"):
    base_planes += circle_outer_planes(obs.position, max_receive_radius, circle_sides)
    linear_planes += bearing_planes(obs.position, obs.bearing_deg, error_deg)
region = _adaptive_circle_intersection(linear_planes, circles, circle_sides,
                                       base_planes=base_planes)
```

两种分支都保守包含真实圆盘；新版是在旧版粗外包上继续收紧，不改变后续候选、FIM 或评分流程。

## 5. 半平面交集怎么求顶点（Q1 的核心，重温）

`intersect_halfplanes` 做的事（`q1/geometry.py:151-205`）：

1. **归一化**：每条 (a,b,c) 除以法向长度 √(a²+b²)，让比较公平。
2. **找候选交点**：任何一对半平面的交线交点，都可能成为多边形的顶点。
   对每两个半平面求交点，用"所有半平面都满足它"来筛选：
   ```
   交点 P = 直线 i 与直线 j 的交
   若 P 满足所有半平面 ⇒ P 是可行顶点，加入列表
   ```
3. **判空**：没有任何可行点 ⇒ 区域为空（无解）。
4. **判无界**：检查四个轴方向 + 每条边法向的"方向向量"，看有没有一个方向
   沿它走永远满足所有约束 ⇒ 无界（不是闭环多边形）。
5. **凸包去重**：把可行交点过一遍 `hull`，删掉重复点和共线内点，得到**逆时针严格凸多边形顶点**。
6. **同时算出**：最小包围圆、直径、直径圆覆盖、面积（这些本是 Q1 的产出，这里直接复用）。

> 复杂度是 O(m³) 对两两求交 + O(n²) 直径，`m` 是半平面数。对本题几十条约束完全够用。

## 6. 保守性的证明与测试

**数学保证**：粗外切多边形以及后来增加的端点/超差切线半平面都包含对应真实圆盘；新半平面只会把粗外包收紧，不会排除真圆内的源。故交集之后依然 ⊇ 真源集合，且细化结果嵌套于旧粗外包，`region["approximation"]["conservative"] = True` 是构造性成立的。

**测试如何验证**（代码层面）：

- `tests/q2/test_unit.py:test_physical_region_is_bounded_and_contains_truth`：
  断言给一个已知真源，真源必须在 P₁ 内。
- `tests/q2/benchmark_200.py:88-89`：200 例的每一例都断言
  `contains(region["planes"], source)`——**合成真源必须落在 P₁ 里**，否则直接 AssertionError。
- `tests/q2/test_duipai.py`：核对"可能接收域包含源域的所有顶点"等包含关系不变量。

这些测试共同守护"不漏真源"这条红线。
