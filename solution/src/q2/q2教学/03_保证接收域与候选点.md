# Q2 零基础教学（03）：保证接收域与离散候选点

有了嫌疑区 P₁，第二测量不能瞎跑。这一篇回答两件事：
**① 在哪一片放 S₂ 是"保证能收到信号"？② 程序实际去检查哪些有限的候选点？**
对应代码 `q2/candidates.py`。

---

## 1. 问题重述：S₂ 得收得到信号

第二次要收到信号，S₂ 到**真正的**干扰源至少要 ≤ 某接收半径。
但我们不知道真源具体在哪、也不知道这台干扰源的有效接收半径有多大（只知道 ≤1500 m）。

最稳的策略是要求：

> **无论真源在 P₁ 里的哪个位置、也无论它的有效接收半径小到多大，
> S₂ 都能收到信号。**

题里给的最小可能接收半径是 **1000 m**，所以条件写成：

```
对 P₁ 里的每一个点 q，都要有  dist(S₂, q) ≤ 1000
等价于  max_{q ∈ P₁} dist(S₂, q) ≤ 1000
```

满足这一整条条件的 S₂ 组成的集合，叫**保证接收域**：

```
F_g = ∩_{q ∈ P₁} B(q, 1000)
```

直观：以 P₁ 的每个点为圆心、1000 m 为半径画一堆圆，
**所有圆都覆盖到的交叠区域**，就是"放在这铁定收得到"的地盘。

---

## 2. 为什么只需检查 P₁ 的"顶点"（关键数学）

上面是对 P₁ 里**所有**点画圆，无数个，没法真做。

而代码文档里说"只需对 P₁ 的顶点施加圆盘约束"，为什么？

**因为"到某个固定点 S₂ 的距离"是凸函数，一个凸函数在凸多边形上的最大值一定发生在顶点上。**

翻译：

- `dist(S₂, q)` 在 P₁ 内部不可能比在顶点更高；
- 所以只要 S₂ 离**所有顶点**都 ≤ 1000 m，它离 P₁ 里任何点也 ≤ 1000 m。

于是无数个约束退化成"对 P₁ 的有穷个顶点各画一个 1000 m 圆"。这就是代码的做法。

我们的 demo：P₁ 是三角形，所以**只用对 3 个顶点各约束一次**，就表达了"S₂ 距整个 P₁ ≤1000"。

## 3. 保证接收域怎么算（算法）

`q2/candidates.py:build_candidate_regions`，核心是对顶点圆盘的**内近似**再求交：

1. 取第一个顶点，用**内接正多边形**（`circle_sides=72`）初始化一块多边形。
2. 对后续每个顶点：
   - 生成该点的内接圆半平面 `_inner_circle_planes(center, R, sides)`；
   - 用 Sutherland–Hodgman 逐半平面**裁剪**当前多边形 `_clip_many`；
   - 裁完还是空就停。
3. 把剩下的多边型整理成带元数据的 `guaranteed_reception`。

**为什么用"内接"、并说它是"内近似"（保守严格）**：

- 内接多边形 ⊂ 真圆盘。所以"落在每个内接多边形里" ⊂ "落在每个真圆盘里"。
- 因此算出的保证域**只可能比真保证域小、不会更大**。
- 现在反过来要的是"收了信号铁定保证"，所以取**小的方向**才安全——
  **返回域里任何点，都确实距 P₁ 一切顶点（进而 P₁ 一切点）≤ 1000 m**。这就是 `relation_to_exact_region="inner"`。

demo：保证域是多边形，约 **35 个顶点**、面积约 **427430 m²**（比 P₁ 大一圈，符合"把圆外扩 1000m"的直觉）。

## 4. 可能接收域（另一个连续域）

除了保证域，代码还算"**可能**收到信号的区域" F_p：

```
F_p = P₁ ⊕ B(0, 1500)     ← P₁ 与半径1500圆盘的 Minkowski 和
    = { s : dist(s, P₁) ≤ 1500 }
```

- 含义：S₂ 只要距 P₁ 不超过最大接收半径 1500 m，就**有可能**收到（取决于真源位置）。
- 它比保证域大得多，作为"别跑到这之外去"的范围参考。
- 计算：对 72 个方向，取支持函数 `max_{q∈P₁} n·q` 再外扩 1500 m，用半平面裁剪求**外近似**。
  `relation_to_exact_region="outer"`（保证覆盖全部可能接收点，画图用）。

demo：可能域约 **72 顶点**、面积 **11745244 m²**，近 12 倍于保证域——差距主要就是保证域把
"到整个 P₁ 所有点"都收在 1000 m，而可能域只要"到其中某一点"≤1500 m 就行。

## 5. 既然是连续的，程序为什么还要"离散候选点"？

FIM 是连续搜索，但**离散基线方案**是从一簸箕有限点里选——为什么？

- 离散有限点**可穷举、可审计**：每个点都能独立复算，方便对拍和论文解释。
- 连续 FIM（第 05 篇）是数值搜索，不能证明全局最优；离散基线是"看得见摸得着"的下界参考。
- 两者互为对照，形成"稳 + 激进"的双保险。

所以离散基线先生成一批候选点，这是 `generate_candidates` 的活。

---

## 6. 离散候选点怎么撒（具体参数）

`q2/candidates.py:generate_candidates`，一次生成几十个点（demo 里 **46 个**）：

**(a) 沿首测方向的前向簇**（20 个）：
- 首测方向的单位向量 `u=(cosθ, sinθ)`，其左法向 `n=(−u.y, u.x)`。
- 4 个前向步长 `forward_steps=(100, 250, 500, 750)` m；
- 每个步长配 5 个横向偏移 `lateral ∈ (0, −0.5·step, +0.5·step, −step, +step)`。
- 生成点：`S₂ = S₁ + forward·u + lateral·n`。

**(b) 绕区域中心的环簇**（25 个）：
- 区域中心 = P₁ 最小包围圆中心；
- 3 个环半径 `center_radii=(250, 500, 750)` m × 每环 8 个角度 `center_angles=8` → 24 点；
- 再加 `S₁ 与中心的中点` → 1 点。

**(c) 区域中心点与保证域质心**（2 个）：
- `(S₁ + center)/2`；
- 若保证域有界，加它的质心 `centroid`。

**去重与清洗**：
- 以 `round(x,9), round(y,9)` 为键做浮点去重；
- 过滤掉非有限数或 `|坐标| > 2,000,000` 的点。

demo：46 个候选里，有 **12 个**落在保证接接收域内（`guaranteed_reception=True`）。
