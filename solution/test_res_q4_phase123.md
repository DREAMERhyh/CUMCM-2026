# B-Q4 前三阶段离线实现与配对结果

> 本文件只记录本地规则替身、几何检查和自动测试，不代表人工验收或官方模拟器成绩。Q4 状态保持【待验证】。

> 这是前三阶段完成时的历史快照。后续原地补测和方向滚动已经实现，当前结果见 `test_res_q4_measurement_strategy.md`；下文“尚未实现”只描述当时状态。

## 实现范围

1. 正确性基线：完整定向探测组、动态四侧偏移、不安全 Q2 单点回退移除、27 m 后验清除网格。
2. 全局扫描优化：以可证明的 37 点、900 m 三角网替代 121 点默认扫描；固定开放路线经 2-opt 后总长 32400 m。
3. 联合后验：有限场景同时包含源位置、全向/定向类型、1000-1500 m 接收半径和定向方向，并使用全部 `direction/no_signal/near` 历史过滤。

Q3 的联合批测、失败清除复测、滚动评价、多源路线、缓存和束搜索没有在 Q4 中启用。

## 自动测试

执行：

```powershell
python -B -m unittest tests.q4.test_offline -v
python -B -m unittest tests.q3.test_offline tests.q4.test_offline tests.sim.test_cli tests.sim.test_smoke -v
python -B -m unittest discover -s tests -t . -v
```

结果分别为 9/9、50/50、120/120 通过；全项目测试耗时 79.792 s。Q4 新增覆盖动态四侧证书、完整探测组不被单点次数截断、37 点结构与密集采样、联合后验利用 `no_signal` 排除全向场景，以及 Q3 新分支继续关闭。

## 发现扫描配对

命令：

```powershell
python -B tests/q4/benchmark_scan.py --cases 8 --seed 20265912 --output output/q4_offline/scan_benchmark.json
```

8 个场景均含 10-16 个全向/定向混合源。两种扫描网均 8/8 完整发现，且 8/8 无源证书正确。

| 平均检测数 | 1256.625 | 361.125 |
| 平均移动距离/m | 63535.534 | 32400.000 |
| 平均扫描虚拟时间/s | 20126.982 | 8611.000 |

37 点方案平均扫描虚拟时间下降 57.217%。

## 完整策略配对

命令：

```powershell
python -B tests/q4/benchmark_policy.py --cases 8 --seed 20266912 --max-actions 10000 --output output/q4_offline/policy_benchmark.json
```

两种方案均 8/8 清除全部源且无源证书正确；triangular37 为 8/8 成对更快。

| 指标 | grid121 | triangular37 |
|---|---:|---:|
| 平均虚拟时间/s | 29520.873 | 18240.103 |
| 中位虚拟时间/s | 29293.651 | 18106.816 |
| 最坏虚拟时间/s | 31204.976 | 20240.612 |
| 平均动作数 | 1825.875 | 1057.875 |
| 平均检测数 | 1209.500 | 353.250 |
| 平均失败清除数 | 601.125 | 689.375 |
| 平均移动距离/m | 102586.865 | 70111.139 |

37 点方案平均虚拟时间下降 38.213%。失败清除数反而增加，说明扫描点减少后，部分源的首次示向几何留下更大的位置后验；当前对半径大于四侧证书适用范围的源会直接进入安全网格清除。因此下一项优化应是大后验区域的定向复测动作，而不是直接启用 Q3 多源路线。
