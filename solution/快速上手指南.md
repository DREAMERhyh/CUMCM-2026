# B 题代码快速上手指南

这套代码按 Q1–Q4 分题放在 `src/`，共享几何、数据模型和时间记账放在 `src/common/`，通用运行层放在 `src/runtime/`，官方模拟器通信放在 `src/sim/`，测试按题或通信层放在 `tests/`。先看本页了解进度，再看分题 README 理解算法、API.md 理解输入输出、verify_manual.md 做人工验收。

```text
solution/
├─ src/
│  ├─ q1/ q2/ q3/ q4/     分题算法、CLI、README 和 Q1/Q2 API
│  ├─ common/              多题共享的数据模型、物理区域和时间模型
│  ├─ runtime/             与传输方式无关的策略执行器及兼容导出
│  ├─ sim/                 官方协议、HTTP客户端、离线替身和现场入口
│  ├─ legacy/              仅为回归保留的旧实验代码
│  └─ TODO.md              尚未实施、仍在讨论的事项
├─ tests/
│  ├─ q1/ q2/              单元测试、对拍、数据生成、人工验证清单
│  ├─ q3/ q4/              已有离线原型测试（不代表模拟器验收）
│  ├─ sim/                 协议、回环HTTP、日志和烟雾策略测试
│  └─ legacy/              旧环境回归
├─ PROJECT_CONTEXT.md      可恢复的当前项目状态
└─ 现状扫描报告.md         本轮重构前的代码盘点
```

状态判定标准：

- 【未开始】：没有可运行代码。
- 【待验证】：代码已写并能本地运行，但尚未由人工按 `verify_manual.md` 验收。

AI 不得把任何题改为【已验证】或【模拟器未测试】。

## 三分钟上手

1. 人工克隆仓库并进入 `solution/`（AI 不执行 Git）。
2. 安装依赖：`python -m pip install -r requirements.txt`。
3. 体验 Q1：`python src/q1/cli.py --demo --no-show --output output/q1.png --result-json output/q1.json`。
4. 体验 Q2：`python src/q2/cli.py --demo --q2-version new --no-show --output output/q2.png --result-json output/q2.json`；旧版对照只需在启动前改为 `--q2-version legacy`。
5. 运行脚本检查：`python tests/q1/test_unit.py` 和 `python tests/q2/test_unit.py`。
6. 阅读 `src/q1/README.md`、`src/q2/README.md`，再由队员按对应 `tests/qN/verify_manual.md` 验收并填写 `test_res.md`。

全量自动测试可用：

```powershell
python -B -m unittest discover -s tests -t . -v
```

只检查模拟器通信层且不连接官方模拟器：

```powershell
python -B -m unittest discover -s tests/sim -t . -v
```

Q3/Q4 各自的 CLI 仍只连接本地规则模型。Q2 源域版本可在各入口启动前用 `--q2-version new|legacy` 选择，默认 `new`。官方模拟器入口是 `src/sim/cli.py`，必须由人工先启动对应演练并显式传入 `--confirm-ready`；完整策略还需要 `--confirm-policy`。具体步骤见 `src/sim/README.md` 和 `tests/sim/verify_manual.md`。
