## 任务 0：地板独立推导与核验

### 0.1 地板构成（每局 N 源，全向，D(0,1800)，R∈[1000,1500]）

**A. 扫描覆盖段（硬地板）**
- 覆盖约束：∀p∈D(0,1800)，∃停点 s：|p−s|≤1000（R 下界保证发现）。
  停点数下界：N 个半径 1000 圆盘覆盖半径 1800 圆盘。面积比给出 N≥4；
  几何更紧：外环带（ρ∈[800,1800]）的覆盖需要环上点——由相邻环点弦长
  与覆盖弧几何，最少 6 个环点 + 中心（hub_ring6）或 8 个环点（pure_ring8），
  N_stop≥7 可达、8 留安全余量（995m 设计裕量）。
- **每个频道必须在其覆盖停点集上全部测过**（absent 认证 = 全盘 no_signal）
  → 每停点测 20 频道 → 检测 20×5=100s/停点、切换 19s/停点（相邻频道互异
  时最优）。
- 移动：ring8 路径 6103m → 1220.7s。**连续覆盖巡回下界**（管式邻域）：
  长度 L 的轨迹其 1000-膨胀覆盖全盘 ⇒ L ≥ π·1800²/(2·1000) ≈ 5089m
  （≈1018s）。螺旋/蛇形可达 ~5500-5800m；是否比 ring8 省由路线重合度决定。
- **扫描段地板 ≈ 移动 1020~1221 + 检测 800 + 切换 152 ≈ 1970~2173s**
  ⇒ 用户给的 2160s 量级正确（差异全在移动项，上限可收割 ~120-150s）。

**B. 清除环游（硬地板）**
- 每源至少一次 /clear（成功 rate 依赖定位质量）；clear 点 = 距源 ≤20m。
- 访问序列最优 = TSP（开放回路）；BHH：L≈0.7124·√(N·π·1800²)
  ⇒ N=10/13/16 → 7188/8197/9082m → 1438/1639/1816s。用户数值正确（✓）。
- 清除动作本身 5s×N（成功 5s；miss 加 3s——证书源不应 miss）。
- 残差定位（见 C）的移动若与环游共享路径（顺路），不计入环游。

**C. 残差定位段（每源：发现后 → 距源 ≤19.9/20m）**
- 1 腿发现：region = 锥形楔（±1°）∩ 1500 接收 ∩ 1800 arena。
  源距测点 d 时锥宽 ≈ 2d·sin1°（d=1000 → 35m；d=1200 → 42m），
  MEC(region) 半径由锥的长边主导 ≈ 30-60m（与 d、方位相关）。
- 达 19.9m 证书需要 ≥1 次高质量交会（顺路第二腿）。**J 方向预实验**：
  两腿交会（交会角 θ 与区域直径 D 的关系 D≈(d1·d2·sinθ)⁻¹ 相关——
  验证在 ring 几何+"顺路"约束下 2 腿是否普遍达标）。
- 地板假设：每源 2 腿（发现+1 交会）+1 clear，腿间移动 ≤150m（顺路骨架
  上绕行），交会腿虚拟 ≈ 移动 30 + 测量 5 + 切换 0-1 ≈ 35s/源；
  clear ≈ 移动 20 + 5 ≈ 25s/源 → 残差定位地板 ≈ 60s/源 → N 档 600~960s？
  **注**：此地板与清除环游共享骨架时可并入环游移动（总移动 = TSPN 总长，
  而非逐项加总）。粗略合并后每源"骨架内绕行"约 20-40s。
- **本项是 450→350 的主要可收割项**（当前 locate 实测 4000-5400s/局 ≈
  其中扫描 ~1760 + 残差 ~2300-3600s，远超 60s/源地板 8-15 倍）。

## 失败方向归因（论文金子）
1. **P2 tour_refine 腿选择器**（4 版 + 同池裁决全负）：名义推演乐观偏置 →
   保证接收域缺位 → 轴外交会缺失 → 预测口径残余偏差；教训=测量腿三要素
   （保证域/横向交会/真相口径预测），FIM 不预测反而稳健。
2. **v8 顺路腿**（放弃于几何论证）：交会角需求与"顺路"本质冲突
   （侧偏 ≥0.58·d），绕行收益 ≤50m/源。
3. **A3 guess_clear 在批量流程无收益**（locate 不走 guess，批量 clear
   99% 证书）——"误翻"风险识别：A3 的有效性限于交错流程（已保留）。
4. **C 连续覆盖巡回**（放弃于工程量级）：扫描段已贴地板（2633→2173→
   覆盖下限 ~1970s；再省需覆盖证明工程，收益 ~120s 且证明负担高）。
